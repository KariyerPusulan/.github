# 🤝 Katkıda Bulun

Bu liste topluluk katkılarına açıktır.

Yeni bir kaynak, program veya düzeltme önermek için:

1. Bu repoyu fork'layın.
2. Gerekli değişikliği yapın.
3. Bir **Pull Request** oluşturun.

Alternatif olarak **Issue** açarak yeni bir kaynak önerebilirsiniz.

Katkı yapılırken mümkün olduğunca:

- Resmî kaynak bağlantısı kullanılmalı,
- Kaynağın adı doğru yazılmalı,
- Ücret, tarih veya uygunluk bilgileri tahmin edilmemeli,
- Süresi dolmuş veya güvenilirliği doğrulanamayan bağlantılar eklenmemelidir.
